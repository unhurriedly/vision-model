# Vision Model 工作台

面向开发者的多模态视觉分析前端原型，覆盖三个连续场景：测试模型效果、集成前端组件、调用后端接口。

## 功能

- **模型测试**：图片、视频、媒体链接、实时流四类输入；图片支持多图切换，视频支持播放与时间轴，实时流提供直播画面。
- **效果预览**：检测框与 Prompt 输出；图片显示单帧 Prompt，视频/链接随播放逐帧追加，实时流持续滚动 YOLO 结果。
- **分析结果**：处理日志（开始处理、分析完成、处理结束，含素材类型、耗时与网络/超时/Token 异常检查）与 JSON 示例（bounding box、置信度、`prompt_result`）。
- **前端组件**：图片、视频、链接、实时流四种预览组件；组件类型下拉与 JSON 代码双向同步，右侧只渲染预览组件。
- **API 集成**：图片、视频、实时流请求配置，cURL / Python / JavaScript 示例与模拟响应。

## 使用

在 Harness 中安装插件后，从侧边栏打开「视觉模型」，工作台会显示在主区域。

也可以不安装插件，直接用浏览器打开 `index.html` 使用独立页面。

## 限制

- 仅前端原型：检测结果、Prompt、YOLO 日志、处理日志与 API 响应均为模拟数据。
- 本地上传仅在浏览器内预览；链接和流地址只做格式校验，不访问真实媒体源。
- 不执行模型推理、实时流转码或计费。
- 插件通过同源静态页面加载工作台，不接入真实后端服务。
